Hints

  • Read the problem carefully and identify whether the input is an array or object.
  • Break the problem into smaller steps: filter, transform, or reduce.
  • Use map to transform arrays and filter to select elements.
  • Use split and join for converting strings into IDs.
  • For object merging, consider { ...obj1, ...obj2 } or Object.assign.
  • Arrow functions are concise callbacks for map, filter, or setTimeout.
  • Rest properties (destructuring with rest) allow removing certain keys from objects.
  • Test each step separately in the console to make debugging easier.
